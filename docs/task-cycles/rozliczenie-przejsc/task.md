Status: ready for cycle
Project relation: plan item: plan_mvp_loop2.md — rozliczenie-przejsc

## Description

### Need

- Dziś każde domknięcie mapy płaci tak samo: wprawa z przejścia wchodzi do umiejętności postaci, a łup do skrzynki, także przy kolejnym ręcznym domknięciu mapy już rozwiązanej (kod loop2 `95de83b`: `advanceMinutes`, `src/browser/sim/game.ts:533`–`562`; D-189, D-194).
- Dziś każdy start bierze wyposażenie ze skrzynki, także start ręcznego przejścia mapy rozwiązanej, więc strojenie programu zjada zapas (`startRun`, `src/browser/sim/game.ts:135`–`140`; D-189).
- Dziś śmierć zabiera tylko to, co postać niosła, i wprawę z tego przejścia: postać nie ma wskrzeszenia ani numeru pokolenia, a jej dorobek przeżywa każdą śmierć (`Character`, `src/browser/sim/types.ts:298`–`304`; D-190, D-194).
- Projekt MVP loop2 obejmuje „Rozliczenie przejść: płaci domknięcie, którego nie da się przewinąć; ręczne powtórzenie mapy rozwiązanej nic nie daje i nic nie kosztuje; śmierć zabiera postać; jedno wskrzeszenie na postać, odnawiane po 8 h realnych (D29, D31).” (definicja, In scope, punkt 17).
- Bez tego zadania przewijane ręczne powtórki płacą tyle co zarobek, a porażka nic nie kosztuje; na tym rozliczeniu stoi pętla zarobkowa (zadanie 18), która zależy od tego zadania.

- Q1. Co obejmuje „nic nie daje i nic nie kosztuje” w ręcznym przejściu mapy rozwiązanej: czy śmierć w takim przejściu kosztuje jak każda inna i czy odkrycia dalej wchodzą do Zrozumienia?
  - Answer: Śmierć w ręcznym przejściu mapy rozwiązanej kosztuje jak każda inna, a odkrycia wchodzą w nim do Zrozumienia jak w każdym przejściu, które uruchamia gracz. W zatwierdzonych wpisach „nie płaci” znaczy: ani wprawą, ani łupem, a „nic nie bierze” dotyczy skrzynki.

The programs, the chest, the Understanding and the solved maps survive every death.” *Verification*, violates: “a manual map run on which death takes nothing”. *Rationale*: “The stake holds on every map run — in the earning loop as on a manual try at a hard map — so a night can be lost.” *Rejected*: “a stake in the earning loop only — everything risky would be done by hand and the stake would vanish where it matters most”.

- Q2. Co rozstrzyga, że przejście jest ręcznym przejściem mapy rozwiązanej — stan mapy w chwili startu czy domknięcia — i co robi „Restart” po domknięciu, które tę mapę rozwiązało?
  - Answer: Rozstrzyga stan mapy w chwili startu przejścia. „Restart” po domknięciu, które rozwiązało mapę, jest już ręcznym przejściem mapy rozwiązanej: nie bierze ze skrzynki, wyposażenie dostaje znikąd i nie płaci niczym.
    - `solved-map-manual-run/1`: “A manual map run of a map already solved when the map run starts leaves the chest as it was and adds no practice to any character skill.”
    - Definicja, „(new) — What pays, and what takes from the chest?”: “A manual map run that first solves its map pays practice and loot once per map for the player, whichever character completes it. A manual run of a solved map pays nothing.”; “A manual map run of a map already solved takes nothing from the chest: it takes its equipment from nowhere, cut only by the character's carrying capacity and the map's cap”. Pojęcie `map run restart`: “A map run restart is a map run of the same character on the same game map, which the player starts in place of the map run in progress or of a map run ended in the character's death or in a completion that still stands on the screen.” Pojęcie `solved map`: “A solved map is a map on which a map run of any of the player's characters has had a completion, whether or not an earning-loop program survives every seed.”

- Q3. Czy gotowe wskrzeszenie ratuje przejście, czy przejście kończy się śmiercią jak dziś, a wskrzeszenie chroni wprawę, stopnie i numer pokolenia?
  - Answer: Gotowe wskrzeszenie nie ratuje przejścia: przejście kończy się śmiercią jak dziś, postać traci to, co niosła, a przejście nie płaci niczym. Wskrzeszenie chroni przed tym, co śmierć zabiera „też”: całą wprawą, każdym wykupionym stopniem i wzrostem numeru pokolenia. Samo się przy tym zużywa.
    - Definicja, „(new) — What does a character's death take?”: “A character's death takes what it carried and pays nothing of its map run; when the character has no resurrection ready, it also takes all its practice and every rank of branch it bought, and the character's generation number grows by one, its archetype unchanged. The programs, the chest, the Understanding and the solved maps survive every death. Each character has one resurrection, used up by a death and renewed after a span of real time set in the balance data, eight hours to start, and a death without one stops the character's earning loop.”
    - D-61: “A character dies in the game minute in which its health reaches zero, also during the character's action in progress, and the map run then ends in death with its cause.”
    - Definicja, „(new) — What pays, and what takes from the chest?”: “a run that ends in death pays neither loot nor practice”.
    - Definicja, „(new) — How fast does the earning loop go?”, dla zadania 18: “Each map run of an earning loop is a map run of its own, followed at once by the next as long as the earning loop goes on.”
