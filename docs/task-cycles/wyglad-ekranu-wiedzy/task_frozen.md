Status: ready for cycle
Project relation: plan item: plan_projektu_2_loop2.md — wyglad-ekranu-wiedzy

## Description

### Need

- Mariusz o ekranie wiedzy: „stara wersja też nie jest dobra; ma być ładniej i czytelniej, zwłaszcza rozpisanie umiejętności.”
- Dziś w prawym obszarze ekranu każde poznane drzewo to przycisk z ramką, szeroki na swój napis, „▸ Zbieranie małych przedmiotów · 3 gałęzie”, więc wiersze drzew mają różną długość i nierówny prawy brzeg.
- Po rozwinięciu drzewa każda gałąź to jeden ciąg w wierszu — nazwa, „3 stopnie”, opis i „1 · 1 · 1 pkt” — łamany tam, gdzie zabraknie miejsca; opis mówi, w którą stronę działa gałąź („Większa szansa zebrania przedmiotu”), ale nie ile daje stopień.
- Lewy obszar, Zrozumienie, stoi w jednej kolumnie: każda poznana rzecz w osobnym wierszu, a stary Loop stawia rzeczy w trzech kolumnach.
- Ekran służy przypomnieniu tego, co gracz już zna (D-416, *Rationale*: „The screen is for recalling what the player already knows.”); kupuje się na ekranie Postać (D-200).
- Zadanie służy celowi projektu: loop2 ma być graficznie „przynajmniej tak samo dobre jak wcześniejsza wersja, a najlepiej lepsze”, żeby Mariusz chciał pokazać grę znajomym; przy tym ekranie stary Loop nie jest wzorcem, bo Mariusz ocenia go jako też niedobry, a miarą jest ekran loop2 przed zmianą.
