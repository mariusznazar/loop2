## Description

- Cel zadania w planie: „Gracz ma „Eksploruj” od pierwszej sekundy, „+ reguła” nigdy nie jest wyłączone, gra dopisuje regułę przy pierwszym wychłodzeniu tylko wtedy, gdy gracz sam jej nie dodał, a u gracza, który sam dodał regułę, pierwsze odkrycie pada do 20. minuty gry.”
