# Glossary

Terms used by this product's foundation.

## game minute

A game minute is the unit of the simulation's time.

- **Avoid:** none
- **Not:** none

## map run

A map run is one attempt of one character at one map, from entering it until a completion, the
character's death or the player stopping it.

- **Avoid:** none
- **Not:** none

## program

A program is the written behaviour by which a character acts, made of ordered program rules and
holding a trip plan.

- **Avoid:** none
- **Not:** none

## program rule

A program rule is a pair of a condition and an action that a program holds.

- **Avoid:** none
- **Not:** none

## restart

A restart is a map run of the same character on the same game map, which the player starts in
place of the map run in progress.

- **Avoid:** none
- **Not:** none
